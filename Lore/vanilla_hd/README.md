## Построчный журнал

[Открыть оглавление блоков](blocks/README.md). Журнал идёт в порядке [ванильного русского ланга](../source/SR_2_HD_Lang_vanilla.txt). Каждая извлечённая запись указана возле исходной строки и попадает в соответствующую статью. Одна строка может дать несколько записей. В статьях у каждой есть только ссылка на ланг с номером строки и ключом. Если просмотрщик GitHub не показывает UTF-16 построчно, эти номера можно открыть в скачанном файле. Суффикс `#N` обозначает повтор одноимённого поля.

В журнале учтены 16 295 русских строк. Полностью проверены блоки `ABMap`, `Achievements` и `Race`. Блок `Artefacts` также пройден полностью, включая сообщения об отказах и совместимости оборудования. Затем последовательно проверены `Asteroid`, `CaseConv`, `Cheat`, `Constellations`, `Economy` и `FormAB`. Титры `FormAbout` учтены как сведения о разработке. Для `FormGS` и `FormGalaxy` извлечены сведения из торговли и карты. Остальные блоки проверены выборочно.

Для содержательных строк по всему файлу журнал показывает полный текст значения с разбивкой по переносам из оригинала. Статус «Текст для сверки» означает, что подробное извлечение фактов ещё предстоит. Под заголовками «Сопоставленные записи» приведены дополнительные редакционные заметки, у которых все исходные значения совпали с ванильным лангом. Полная сверка формулировок и контекста этих заметок ещё не завершена. У каждой заметки есть прямые ссылки на все сопоставленные строки.
