# Корабельное оборудование следующей игры

Рабочая линейка модового лора. Классы A и B перекрываются с G и H КР2 и сохраняют названия семейств. Классы C–H добавляют ГТУ 15–20. Характеристики серийных исполнений определяются при балансировке.

В скобках указан доминаторский прототип, чей принцип работы адаптирован в коалиционной модели. Строки A–B повторяют модели и описания из [линейки КР2](MOD_LORE_EQUIPMENT_SR2.md), а прототипы описаны в её [доминаторском разделе](MOD_LORE_EQUIPMENT_GTU.md#доминаторское-оборудование).

## A / ГТУ 13. Управление на малом масштабе

Соответствует классу G КР2.

| Оборудование | Принцип работы |
|---|---|
| **Нанохитиновый корпус** | Наружные пластины состоят из нановолокон в хитиноподобной матрице. Волокна удерживают мелкие трещины, а матрица распределяет удар. Возможная связь с клисанской бронёй остаётся гипотезой. |
| **Стансерный двигатель** | «Стансер» предлагается трактовать как узел из нескольких малых излучателей. Они по очереди поддерживают соседние участки тягового поля и гиперперехода. Это даёт более ровную тягу и дальний прыжок в пределах допустимого искривления. Происхождение самого названия открыто. |
| **Гироскопический бак** | Вращающийся барабан с плотным запасом сохраняет ориентацию на подвесе при манёвре. Топливо отбирается через центральную магистраль. Стабильная подача позволяет уменьшить расходную камеру и отдать больше объёма под основной запас. |
| **Этановый радар** | По рабочей гипотезе, в камере используется охлаждённый этан как чувствительная среда. Слабое электромагнитное эхо преобразуется в считываемое изменение оптических свойств среды. Это предложенное фантастическое объяснение названия и увеличения дальности. |
| **Деатомарный сканер** | Различает отклики отдельных элементов в составе предметов. По их сочетаниям восстанавливает состав груза даже при сильном ослаблении сигнала защитой. |
| **Штифтовый дроид** | Сшивает уцелевшие края повреждённой плиты короткими штифтами, ориентируя их по данным о нагрузке. Такая фиксация позволяет быстрее вернуть прочность до завершения наружной заплаты. |
| **Оптоволновой захват** | Волоконная сеть распределяет импульсы от общего источника по разнесённым излучателям и согласует их работу. Поле меньше теряет форму на дистанции, поэтому захват удерживает более тяжёлый груз. |
| **Микроуровневый генератор защиты** | Делит защитную оболочку на множество малых областей. При попадании включает нужные области и ближайшее окружение, концентрируя мощность в месте удара. |

## B / ГТУ 14. Точная настройка материалов, полей и сигналов

Соответствует классу H КР2.

| Оборудование | Принцип работы |
|---|---|
| **Биослотовый корпус** | В силовом наборе предусмотрены посадочные гнёзда с биокомпозитными стенками. Они обрастают установленную деталь и передают нагрузку в обшивку без ослабления вокруг крепления. Название отсылает к клисанским биослотам в мегапанцире, которые клисаны могли заращивать оружием. |
| **Темпоральный двигатель** | Синхронизирует излучатели по локальному времени в разных частях гиперперехода. При искажении хода времени автоматика корректирует момент подачи каждого импульса. Переход остаётся устойчивым дольше, поэтому растёт дальность прыжка в пределах допустимого искривления. |
| **Текриновый топливный бак** | В рабочей трактовке текрин — материал тонких внутренних перегородок, удерживающих топливо в плотном состоянии. При подаче освобождается только ближайшая к выходу порция. Неподвижное хранилище обходится без вращающегося барабана и оставляет больше места под запас. |
| **Нуль-контактный радар** | Измеряет, как масса объекта меняет фазу контрольного сигнала на проходящей рядом трассе. Для обнаружения достаточно уловить это возмущение. Название относится к режиму, в котором зондирующий сигнал проходит мимо цели, а дальность выигрывает за счёт чувствительности к слабым изменениям фазы. |
| **Кванторный сканер** | Измеряет отдельные порции энергии в отклике и по их сочетаниям восстанавливает сигнатуры вещества. Деатомарный определял, какие элементы есть в грузе. Кванторный различает ещё и состояния, в которых они находятся, поэтому может распознать характерные материалы даже по неполному сигналу из-под защиты. |
| **Дуплексный дроид** | Две рабочие головки действуют с разных сторон повреждения. Пока одна фиксирует края и ставит штифты, вторая закрывает пробоину и проверяет, как шов держит нагрузку. Параллельная работа ускоряет восстановление обшивки. |
| **Микротональный захват** | Меняет частоту тягового поля малыми шагами и по отклику подбирает режим для разных частей груза. Это позволяет распределить тягу по объекту и удержать его при вращении. По сравнению с оптоволновым захватом точнее настраивается само воздействие на груз. |
| **Ультраплазменный генератор защиты** | Удерживает в поле многослойный веер сильно ионизированной плазмы. Наружные слои поглощают часть энергии удара и отводят её вдоль оболочки, внутренние поддерживают защиту, пока внешний слой восстанавливается. Для мода это позднее развитие клисанского плазмощита, у которого плазма уже поглощала энергию. |

## C / ГТУ 15. Первые серийные адаптации

| Оборудование | Принцип работы |
|---|---|
| Сегментированный корпус | Сменные броневые секции отделены сминаемыми вставками. При сильном ударе вставки принимают часть нагрузки, поэтому повреждённая плита реже срывает соседние с креплений. |
| Контурный двигатель | Раздельные буферы питания поддерживают тягу при зарядке прыжкового контура. Во время прыжка его собственный буфер помогает дольше удерживать поле в разрешённых пределах. |
| Стековый бак (Стекбаррель) | Плоские герметичные ячейки плотно уложены вокруг общего коллектора. Меньше объёма уходит на промежутки и подводящие линии. Ячейки подключаются поочерёдно, и повреждённую можно изолировать. |
| Многоапертурный радар | Разнесённые головки измеряют возмущение контрольного сигнала по принципу нуль-контактного радара. Сопоставление замеров выделяет слабый сигнал цели на большей дальности. |
| Импульсно-спектральный сканер | Разбирает кванторный отклик по коротким временным интервалам. Это помогает выделять слабые сигналы содержимого после сильного раннего отклика защиты. |
| Дианодный дроид (Дианод) | Удерживает края пробоины, пока головка смешивает и укладывает быстротвердеющий состав. Трещины заполняются за один проход, поэтому за цикл восстанавливается больше обшивки. |
| Многолучевой захват | Несколько участков тягового поля подхватывают разные части обломка. Распределённая тяга гасит вращение и позволяет вести более массивный груз. |
| Импульсно-плазменный генератор защиты | По прогнозу попадания короткий импульс уплотняет наружный слой плазменного веера в нужном секторе. Защита поглощает больше энергии при той же средней мощности. |

## D–H / ГТУ 16–20. Дальнейшее развитие

- **D.** Сенсотронный радар согласует сигналы разнесённых приёмников по принципу Сенсотрона. Сигнатурный сканер использует метод Тех-детектора для распознавания отдельных устройств. Обзорные данные позволяют направить сканирование на нужный участок цели. Пакетно-компрессионный бак сохраняет пакетную укладку Стекбарреля и повышает плотность хранимого запаса.
- **E.** Ментокинезный захват адаптирует направленный поток Ментощупа и меняет распределение тяги по мере движения груза. Пикселитовый генератор использует управление ячейками Пикселита. Коалиционным предшественником точечной защиты остаётся микроуровневый генератор КР2.
- **F.** Торсионный двигатель переносит согласование тяговых и прыжковых излучателей Торсионного реактора в коалиционную конструкцию. Устойчивость поля увеличивает дальность прыжка в пределах допустимого искривления. Объёмно-ментокинезный захват развивает поток Ментощупа и точнее распределяет тягу по крупному обломку.
- **G–H.** Прирост дают более точное управление, уменьшение потерь и согласованная работа узлов. Адаптивно-торсионный двигатель подстраивает согласование излучателей Торсионного реактора по текущей нагрузке. Самоперестраиваемый корпус перераспределяет нагрузку между уцелевшими секциями, а обшивку восстанавливает дроид.
