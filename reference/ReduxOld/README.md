Источник: архив пользователя UniOriginal.zip (2026-10-11).
- `Rus/<Группа>/<Мод>/CFG/Rus/Lang.txt` — старый русский оригинал; `Eng/…/CFG/Eng/Lang.txt` — старый английский перевод.
- Сравнение со ТЕКУЩИМ `ToTranslate/` — по ключам (путь блоков + номер): `python3 reference/ReduxOld/diff_old.py < /dev/null`
  → `DIFF_REPORT.md` (по каждому моду: без изменений / изменено / новых / удалено) и `pairs.tsv` (RU→EN строк, чей русский текст НЕ изменился — старый перевод актуален).

Правила: справочник, автоматически не подставлять; перевод «неизменённых» строк брать как подсказку и сверять с терминами
(приоритет: ванилла > DevTranslated > наши переводы > ReduxOld). «Изменённые» и «новые» строки переводим заново (старый EN — только подсказка).
