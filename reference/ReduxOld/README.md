# ReduxOld — старый английский перевод пака Universe Redux (справочник)

Источник: архив пользователя UniOriginal.zip (2026-10-11). Только английские `CFG/Eng/Lang.txt` очень старой версии пака
(124 мода, группы Evolution, Expansion, OtherMods, PlanetaryBattles, Revolution, ShusRangers, Tweaks).
Русских пар нет: сопоставлять с `ToTranslate/<Группа>/<Мод>/CFG/Rus/Lang.txt` по ключам (120 из 124 имеют пару;
без пары: Evolution/EvoArmada, Evolution/EvoJamming, Revolution/RevBomber, Tweaks/SR2Balance).

Правила использования: СПРАВОЧНИК, ничего не подставлять автоматически. Приоритет терминов:
ванилла > DevTranslated > наши переводы > ReduxOld. Тексты в нём могут быть устаревшими (изменились после той версии).
Файлы не менять.
