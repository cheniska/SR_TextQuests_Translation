# Вычитка готового английского (корпус КР1, SR1TextQuests)

Для квестов, у которых английский уже есть (перевод КР1), перевод с нуля не нужен: проверяем **грамматику, соответствие оригиналу и единообразие**. Правила `TRANSLATION_GUIDE.md` (только txt, RU не менять, термины в глоссарий, повторы одинаково, отчёт о новых терминах) действуют полностью. Лор — по `LORE_GUIDE.md`.

Пример выполненной вычитки: **Bank** (2026-09-30). Заметки: `TextQuests\SR1TextQuests\Eng\notes\Bank_notes.txt`, журнал правок: `Eng\notes\Bank_fixes.txt`.

## Пути
| Что | Где |
|---|---|
| RU | `QUESTS\TextQuests\SR1TextQuests\Rus\<Name>.txt` |
| EN (результат) | `QUESTS\TextQuests\SR1TextQuests\Eng\<Name>.txt` (именно его правим; КР1-оригинал сохранён в `0_квесты кр 1 в тхт англ\qmm\<Name>.txt`) |
| Рабочие файлы | `QUESTS\Translation\work\<Name>.*` (после сессии удалить, правки сохранить как `Eng\notes\<Name>_fixes.txt`) |
| Инструменты | `QUESTS\qtr.py`, `qtr_sbs.py`, `qtr_heur.py`, `qtr_apply.py`, `qtr_post.py` |

Все команды: `export PYTHONUTF8=1` и `py -3.14 файл.py ... < /dev/null` (НИКОГДА `py -3.14 -`). Длинный вывод лучше писать в файл и читать `Read` (вывод Bash >30 КБ обрезается).

## Шаги
1. **Срез:** `py -3.14 qtr.py check Eng\X.txt Rus\X.txt < /dev/null` — ошибки КР1-варианта (токены, одинаковый RU → разный EN). Проверить, что в Eng лежит именно английский (нет кириллицы); файлы вида `…rus - NN тыс.txt` — обычно русский текст (см. STATUS).
2. **Рабочая копия:** `py -3.14 qtr.py unpack Eng\X.txt < /dev/null` → `work\X.work.txt` (UTF-8). Сразу `cp work\X.work.txt work\X.orig.txt` (все правки применяются к orig, идемпотентно).
3. **Сверка с оригиналом:** `py -3.14 qtr_heur.py Rus\X.txt Eng\X.txt < /dev/null` (цифры, абзацы, длины, число предложений — подозрительные места) и построчный просмотр пар RU/EN: `py -3.14 qtr_sbs.py Rus\X.txt work\X.orig.txt 0 25 < /dev/null > out.txt`, затем `Read out.txt` (по ~25–60 уникальных записей за раз). Искать: пропущенные/лишние предложения, перепутанные числа/время (например «половина второго» = 13:30, «половина восьмого» = 19:30), ложные друзья, шутки, которые КР1 потерял.
4. **Файл правок** `work\X.fixes.txt` (UTF-8), по строке:
   - `old ==> new` — глобальная замена подстроки во всех записях (каждая правка сразу применяется ко всем повторам; порядок важен: сначала точечные, в конце глобальные замены имён);
   - `[Path123] old ==> new` — только в записях, у которых RU совпадает с RU записи Path123;
   - `@Loc89-2 ==> полный текст` — запись целиком (абзацы через ` ¶ `), заодно все записи с тем же RU;
   - `#` — комментарий. Маркер абзаца в `old` тоже ` ¶ `. Нельзя начинать `old` с `@`.
5. **Сборка:** `py -3.14 qtr_apply.py work\X.orig.txt work\X.fixes.txt Rus\X.txt work\X.fixed.txt < /dev/null` (печатает `NOFIND` для правок, не нашедших цель — разобрать каждую), затем `py -3.14 qtr_post.py work\X.fixed.txt work\X.work.txt < /dev/null` (нормализует пробелы внутри `<clr>…<clrEnd>` и ведущие пробелы реплик), затем `py -3.14 qtr.py check work\X.work.txt Rus\X.txt < /dev/null` — 0 ошибок и 0 предупреждений. Эти три команды удобно держать в одном sh-скрипте и запускать после каждой порции правок.
6. **Прочитать результат** целиком (`Read work\X.work.txt`), поправить оставшееся во втором проходе (добавить в fixes и пересобрать). Повторы (одинаковый RU) приводятся к одному EN автоматически, near-дубли — следить вручную (check предупреждает).
7. **Запись:** `py -3.14 qtr.py pack work\X.work.txt Rus\X.txt Eng\X.txt < /dev/null`. Затем проверка структуры: `py -3.14 qtr_struct.py Eng\X.txt Rus\X.txt < /dev/null` (BOM, CRLF, типы и порядок записей, число строк и пустые абзацы как в RU) — 0 расхождений.
8. **Учёт:** `Eng\notes\X_notes.txt` (образец — Bank_notes.txt; типы СМЫСЛ, ГРАММАТИКА, ЕДИНООБРАЗИЕ, ПОТЕРЯ, СОМНЕНИЕ, ПАРОДИЯ, ТЕРМИН); `cat work\X.fixes*.txt > Eng\notes\X_fixes.txt`; термины — в `GLOSSARY.md` (и сообщить пользователю); лор — в `lore\LORE_FACTS.md`; строка в `STATUS.md`; удалить `work\X.*`.

## Что обычно правим в КР1-варианте
- Смысл: числа и время, пропущенные предложения, «скопированные» абзацы (вариант записи скопирован из соседней), перепутанные стороны (host/away), шахматная нотация (русские «Кр»/«К» = King/Knight → K/N), идиомы, переведённые буквально.
- Единообразие: имена и термины по `GLOSSARY.md` (Hachball, Shvakh, Jlobber, Khryamba, Resident Ool, Pelengan, Gaalian, Iike-Baana, Maloq и т.д.); одинаковые метки выбора; написание disc, banzai, 1,000 / 50,000.
- Грамматика: времена, порядок слов, артикли, притяжательные (its/it's), пунктуация, лишние пробелы, потерянные кавычки.
- Токены разметки (`<clr>`, `<Ranger>` …) — восстанавливать; `check` ловит потери.
- Числа-пароли, коды, время в формате `0.32` — не менять.
