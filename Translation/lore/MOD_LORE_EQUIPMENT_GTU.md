# Корабельное оборудование КР1 и КР2 по ГТУ

Свод описаний для модового лора. Названия и последовательность внутри игр опираются на русские ланги. Сопоставление ступеней двух игр и принципы работы оборудования разработаны для модов. Общая шкала описывает поколения техники, а игровые классы A–H относятся к исполнениям в каждой игре.

[Русский ланг КР1](source/SR1_rus.txt) · [Русский ланг КР2](source/SR2_rus.txt) · [Послевоенная эволюция оборудования](MOD_LORE_EQUIPMENT.md)

В ланге КР1 рогост — ороговевший слой клеток-рефлекторов клисанской брони. Жабродюзы — жаберные щели, выбрасывающие плазму. Нейрощуп сканирует неживые объекты, а плазмонить собирает добычу струёй с обратным тяготением. Протопузырь хранит топливо для жабродюз в ёмкости с мускульными стенками. Радиосенсоры состоят из органов с электромагнитными рецепторами. Плазмощит поглощает энергию упорядоченным веером плазмы, а биорегенератор восстанавливает обшивку кристальной протоплазмой. Происхождение названия катаурного радара связывается с подвидом клисан катаури. Прямая технологическая преемственность коалиционных устройств — трактовка для мода.

## ГТУ 1. Базовые механизмы и локальные поля

КР1

| Оборудование | Принцип работы |
|---|---|
| **Титановый корпус** | Плиты из титанового сплава гасят часть удара деформацией и передают остальную нагрузку рёбрам корпуса. |
| **Реакторный двигатель** | Общий реактор питает тяговый привод и накопитель прыжкового контура. Мощность реактора ограничивает оба режима. |
| **Статичный бак** | Топливо хранится в постоянном объёме и в одной фазе. Перегородки удерживают его возле заборника при манёврах. |
| **Визионный радар** | Строит обзорную картину по отражениям от объектов, последовательно просматривая сектора. |
| **Аналоговый сканер** | Аналоговые фильтры различают отклики материалов и устройств. Сильное защитное поле делает отклик неразборчивым. |
| **Рельсовый дроид** | Ремонтная каретка движется по направляющим на корпусе и ставит заплаты в пределах досягаемости инструмента. |
| **Магнитный захват** | Луч временно поляризует материал цели, а поле тянет её к приёмному отсеку. |
| **Точечный генератор защиты** | Создаёт небольшое поле в расчётном месте попадания, где оно поглощает часть энергии удара. |

## ГТУ 2. Согласование рабочих узлов

КР1

| Оборудование | Принцип работы |
|---|---|
| **Рениумный корпус** | Тонкая силовая прослойка из рениумного сплава распределяет удар от наружной плиты по соседним креплениям. |
| **Фазовый двигатель** | Два контура работают со сдвигом по фазе. Они подхватывают тягу друг друга и совместно поддерживают гиперпереход. |
| **Накопительный бак** | Внутренние кассеты удерживают часть топлива в плотной форме и отдают её по мере опустошения расходного резервуара. |
| **Анимирующий радар** | Совмещает несколько обзоров, строит траектории и обновляет положение отметок между замерами. Повторные слабые отклики помогают обнаружить цель дальше. |
| **Биполярный сканер** | Сопоставляет отклики на импульсы противоположной полярности, чтобы лучше выделять сигнал содержимого из помех защиты. |
| **Шарнирный дроид** | Многозвенный манипулятор огибает выступы и прикладывает заплату под нужным углом. Меньше времени уходит на перестановку каретки. |
| **Селероидный захват** | Фокусирующее кольцо из селероида разделяет поле на дальнюю область подхвата и ближнюю область подачи к отсеку. |
| **Пучковый генератор защиты** | Несколько полевых пучков пересекаются в ожидаемой точке попадания и создают более плотную локальную защиту. |

## ГТУ 3. Короткие воздействия и быстрый обзор

КР1

| Оборудование | Принцип работы |
|---|---|
| **Селениновый корпус** | Мелкие прочные плиты из селенина принимают резкие удары. Швы мешают трещине перейти на соседнюю плиту. |
| **Импульсный двигатель** | Согласованные контуры выдают накопленную энергию короткими порциями. Серия импульсов даёт тягу, а мощный импульс открывает гиперпереход. |
| **Вихревой бак** | Вращение отделяет газовые включения у оси, плотная фракция остаётся возле стенок и поступает в магистраль. |
| **Веерный радар** | Несколько расходящихся лучей охватывают широкий сектор за цикл, позволяя чаще проверять слабые отметки. |
| **Текрановый сканер** | Многосекционная пластинка из текрана разделяет отражения по углу и месту прихода. |
| **Пневматический дроид** | Свободно перемещается вокруг корабля короткими выбросами сжатого газа. У пробоины цепляется за обшивку и ремонтирует её манипулятором. |
| **Псевдовакуумный захват** | Создаёт направленную зону втягивания, в которой груз движется к отсеку словно под действием всасывания. |
| **Антимерный генератор защиты** | Формирует встречный градиент поля вдоль направления удара и ослабляет воздействие на подходе к обшивке. |

| **Динамический дроид** | Компенсирует манёвры корабля, удерживает положение возле повреждённой секции и выравнивает скорость для стыковки. |

| **Рассеивающий генератор защиты** | Распределяет энергию удара по большей площади поля, снижая нагрузку на отдельный участок обшивки. |

| **Голографический генератор защиты** | Интерференция полей создаёт объёмный рисунок защиты с несколькими усиленными участками. |

## ГТУ 7. Формирование поля вокруг корабля

Переход КР1 → КР2

| Оборудование | Принцип работы |
|---|---|
| **Гравикорный корпус** | Гравитационный сердечник кратковременно распределяет нагрузку от попадания между рёбрами корпуса. В базовых сериях КР2 обшивку облегчили. |
| **Нырковый двигатель** | Поэтапно смещает поле вокруг корабля, постепенно вводя его в гиперпереход. Послевоенное исполнение получило безопасный режим прыжка и упрощённый внутрисистемный привод. |
| **Аквапунктирный бак (КР1) / гипержидкостный бак (КР2)** | Первый использует массив мелких камер с точечной подачей. Второй хранит топливо в плотной текучей фазе. Его военное исполнение относится к ГТУ 8 КР1, а дешёвое серийное открывает линейку КР2. |
| **Релятивный радар (КР1) / волновой радар (КР2)** | Релятивный совмещает эхо с поправкой на движение и задержку сигнала. Волновой сохраняет эти поправки и сверяет отражения в нескольких диапазонах. Менее мощный излучатель сокращает дальность и снижает нагрузку на энергосеть. |
| **Трассионный сканер** | По первому отклику прокладывает узкую трассу зондирования через защиту к нужному отсеку. |
| **Биотический дроид** | Наносит состав, который заполняет неровности и твердеет, пока дроид готовит соседний участок. |
| **Активаторный захват** | Коротким импульсом повышает восприимчивость цели к тяговому полю и затем подтягивает её основным лучом. |
| **Экранирующий генератор (КР1) / коротковолновый генератор (КР2)** | Первый ослабляет удар несколькими слоями поля. Второй формирует один тонкий слой у обшивки и рассчитан на штатное питание серийных кораблей. |

## ГТУ 8. Управление внутренней структурой

Переход КР1 → КР2

| Оборудование | Принцип работы |
|---|---|
| **Мезоструктурный корпус** | Внутренняя сеть перемычек в бронеплите последовательно деформируется под ударом. Более дешёвые варианты конструкции пошли в массовые серии КР2. |
| **Сингулярный двигатель** | Формирует гиперпереход вокруг компактного фокуса искривления. Послевоенное исполнение ограничивает искривление вследствие запрета режимов с риском коллапса в чёрную дыру. |
| **Гипержидкостный бак (КР1) / конденсатный бак (КР2)** | Первый хранит запас в плотной текучей фазе. Во второй на заправке осаждают плотный твёрдый конденсат. В полёте бак разжижает тонкий поверхностный слой и подаёт топливо в расходную камеру. |
| **Субтрансферный радар** | Часть сигнала проходит через приграничный слой гиперпространства. Прибор сверяет отклик с обычным эхо. У серийного исполнения КР2 меньшая мощность и дальность. |
| **Вортексный сканер** | Вращающееся поле зондирования собирает отклики под разными углами и выделяет устойчивые признаки содержимого. |
| **Суспензорный дроид** | Удерживает ремонтную взвесь полем, распределяет её по форме пробоины и закрепляет на обшивке. |
| **Телекинетический захват** | Воздействует на объём груза, подтягивая его и гася вращение. Серийная модель КР2 рассчитана на питание малого корабля. |
| **Октогенный генератор (КР1) / поляризующий генератор (КР2)** | Первый поддерживает оболочку восемью согласованными излучателями. Второй меняет направленность защитного поля при угрозе. |

## ГТУ 14. Точная настройка материалов, полей и сигналов

КР2 · рабочий вариант для мода. Трактовки принципов работы предложены для обсуждения.

| Оборудование | Принцип работы |
|---|---|
| **Биослотовый корпус** | В силовом наборе предусмотрены посадочные гнёзда с биокомпозитными стенками. Они обрастают установленную деталь и передают нагрузку в обшивку без ослабления вокруг крепления. Название отсылает к клисанским биослотам в мегапанцире, которые клисаны могли заращивать оружием. |
| **Темпоральный двигатель** | Синхронизирует излучатели по локальному времени в разных частях гиперперехода. При искажении хода времени автоматика корректирует момент подачи каждого импульса. Переход остаётся устойчивым дольше, поэтому растёт дальность прыжка в пределах допустимого искривления. |
| **Текриновый топливный бак** | В рабочей трактовке текрин — материал тонких внутренних перегородок, удерживающих топливо в плотном состоянии. При подаче освобождается только ближайшая к выходу порция. Неподвижное хранилище обходится без вращающегося барабана и оставляет больше места под запас. |
| **Нуль-контактный радар** | Измеряет, как масса объекта меняет фазу контрольного сигнала на проходящей рядом трассе. Для обнаружения достаточно уловить это возмущение. Название относится к режиму, в котором зондирующий сигнал проходит мимо цели, а дальность выигрывает за счёт чувствительности к слабым изменениям фазы. |
| **Кванторный сканер** | Измеряет отдельные порции энергии в отклике и по их сочетаниям восстанавливает сигнатуры вещества. Деатомарный определял, какие элементы есть в грузе. Кванторный различает ещё и состояния, в которых они находятся, поэтому может распознать характерные материалы даже по неполному сигналу из-под защиты. |
| **Дуплексный дроид** | Две рабочие головки действуют с разных сторон повреждения. Пока одна фиксирует края и ставит штифты, вторая закрывает пробоину и проверяет, как шов держит нагрузку. Параллельная работа ускоряет восстановление обшивки. |
| **Микротональный захват** | Меняет частоту тягового поля малыми шагами и по отклику подбирает режим для разных частей груза. Это позволяет распределить тягу по объекту и удержать его при вращении. По сравнению с оптоволновым захватом точнее настраивается само воздействие на груз. |
| **Ультраплазменный генератор защиты** | Удерживает в поле многослойный веер сильно ионизированной плазмы. Наружные слои поглощают часть энергии удара и отводят её вдоль оболочки, внутренние поддерживают защиту, пока внешний слой восстанавливается. Для мода это позднее развитие клисанского плазмощита, у которого плазма уже поглощала энергию. |
