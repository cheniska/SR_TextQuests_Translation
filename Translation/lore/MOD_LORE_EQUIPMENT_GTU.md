# Корабельное оборудование КР1 и КР2 по ГТУ

Свод описаний для модового лора. Названия и последовательность внутри игр опираются на русские ланги. Сопоставление ступеней двух игр и принципы работы оборудования разработаны для модов. Общая шкала описывает поколения техники, а игровые классы A–H относятся к исполнениям в каждой игре.

[Русский ланг КР1](source/SR1_rus.txt) · [Русский ланг КР2](source/SR2_rus.txt) · [Послевоенная эволюция оборудования](MOD_LORE_EQUIPMENT.md)

В ланге КР1 рогост — ороговевший слой клеток-рефлекторов клисанской брони. Жабродюзы — жаберные щели, выбрасывающие плазму. Нейрощуп сканирует неживые объекты, а плазмонить собирает добычу струёй с обратным тяготением. Протопузырь хранит топливо для жабродюз в ёмкости с мускульными стенками. Радиосенсоры состоят из органов с электромагнитными рецепторами. Плазмощит поглощает энергию упорядоченным веером плазмы, а биорегенератор восстанавливает обшивку кристальной протоплазмой. Происхождение названия катаурного радара связывается с подвидом клисан катаури. Прямая технологическая преемственность коалиционных устройств — трактовка для мода.

## ГТУ 1. Базовые механизмы и локальные поля

КР1

| Оборудование | Принцип работы |
|---|---|
| **Титановый корпус** | Плиты из титанового сплава гасят часть удара деформацией и передают остальную нагрузку рёбрам корпуса. |
| **Реакторный двигатель** | Общий реактор питает тяговый привод и накопитель прыжкового контура. Мощность реактора ограничивает оба режима. |
| **Статичный бак** | Топливо хранится в постоянном объёме и в одной фазе. Перегородки удерживают его возле заборника при манёврах. |
| **Визионный радар** | Строит обзорную картину по отражениям от объектов, последовательно просматривая сектора. |
| **Аналоговый сканер** | Аналоговые фильтры различают отклики материалов и устройств. Сильное защитное поле делает отклик неразборчивым. |
| **Рельсовый дроид** | Ремонтная каретка движется по направляющим на корпусе и ставит заплаты в пределах досягаемости инструмента. |
| **Магнитный захват** | Луч временно поляризует материал цели, а поле тянет её к приёмному отсеку. |
| **Точечный генератор защиты** | Создаёт небольшое поле в расчётном месте попадания, где оно поглощает часть энергии удара. |

## ГТУ 2. Согласование рабочих узлов

КР1

| Оборудование | Принцип работы |
|---|---|
| **Рениумный корпус** | Тонкая силовая прослойка из рениумного сплава распределяет удар от наружной плиты по соседним креплениям. |
| **Фазовый двигатель** | Два контура работают со сдвигом по фазе. Они подхватывают тягу друг друга и совместно поддерживают гиперпереход. |
| **Накопительный бак** | Внутренние кассеты удерживают часть топлива в плотной форме и отдают её по мере опустошения расходного резервуара. |
| **Анимирующий радар** | Совмещает несколько обзоров, строит траектории и обновляет положение отметок между замерами. Повторные слабые отклики помогают обнаружить цель дальше. |
| **Биполярный сканер** | Сопоставляет отклики на импульсы противоположной полярности, чтобы лучше выделять сигнал содержимого из помех защиты. |
| **Шарнирный дроид** | Многозвенный манипулятор огибает выступы и прикладывает заплату под нужным углом. Меньше времени уходит на перестановку каретки. |
| **Селероидный захват** | Фокусирующее кольцо из селероида разделяет поле на дальнюю область подхвата и ближнюю область подачи к отсеку. |
| **Пучковый генератор защиты** | Несколько полевых пучков пересекаются в ожидаемой точке попадания и создают более плотную локальную защиту. |

## Соответствие оборудования «Детей Эльтан»

Утверждённые названия взяты из [линеек «Детей Эльтан»](https://github.com/cheniska/Eltan/blob/main/docs/gameplay/Equipment_Names.md). По характеристикам уровни 1–8 мода соответствуют уровням A–H КР2. В сквозной шкале этого файла это ГТУ 7–14. ГТУ 6 приведён как предшествующий уровень КР1. Описания принципов работы предложены для лора. Утверждённые названия «Эльтана» имеют приоритет при совпадениях с черновыми названиями ГТУ 15–21.

## ГТУ 7. Формирование поля вокруг корабля

Переход КР1 → КР2

| Оборудование КР1 / КР2 | Принцип работы | «Дети Эльтан» |
|---|---|---|
| **Гравикорный корпус** | Гравитационный сердечник кратковременно распределяет нагрузку от попадания между рёбрами корпуса. В базовых сериях КР2 обшивку облегчили. | **Рамный корпус**. Продольная рама и поперечные рёбра принимают нагрузку от сменных плит. Рама принимает общий изгиб корпуса, а повреждённую плиту можно заменить в порту отдельно. |
| **Нырковый двигатель** | Поэтапно смещает поле вокруг корабля, постепенно вводя его в гиперпереход. Послевоенное исполнение получило безопасный режим прыжка и упрощённый внутрисистемный привод. | **Роторный двигатель**. Ротор дозирует подачу рабочего тела и выравнивает тягу. Прыжковый контур получает питание от той же установки. Вращение сглаживает перепады подачи при разгоне. Дальность прыжка ограничивает мощность, которую установка может отдать прыжковому контуру. |
| **Аквапунктирный бак (КР1) / гипержидкостный бак (КР2)** | Первый использует массив мелких камер с точечной подачей. Второй хранит топливо в плотной текучей фазе. Его военное исполнение относится к ГТУ 8 КР1, а дешёвое серийное открывает линейку КР2. | **Кассетный топливный бак**. Сменные кассеты упрощают заправку и изолируют повреждённую ёмкость. Каждая кассета имеет собственный клапан. При пробоине экипаж отключает повреждённую кассету и сохраняет остальной запас. |
| **Релятивный радар (КР1) / волновой радар (КР2)** | Релятивный совмещает эхо с поправкой на движение и задержку сигнала. Волновой сохраняет эти поправки и сверяет отражения в нескольких диапазонах. Менее мощный излучатель сокращает дальность и снижает нагрузку на энергосеть. | **Секторный радар**. Антенна поочерёдно опрашивает сектора. Одна антенна расходует всю мощность на выбранное направление. Цена простой конструкции — задержка между повторными обзорами сектора. |
| **Трассионный сканер** | По первому отклику прокладывает узкую трассу зондирования через защиту к нужному отсеку. | **Оптический сканер**. Оптическая головка разбирает спектр отклика от содержимого цели. Спектр показывает характерные признаки материалов в трюме. Сильное защитное поле размывает эти признаки и ограничивает глубину сканирования. |
| **Биотический дроид** | Наносит состав, который заполняет неровности и твердеет, пока дроид готовит соседний участок. | **Сборочный дроид**. Механический манипулятор подгоняет и закрепляет готовые ремонтные детали. Дроид возит стандартные заплаты и ставит их по одной. Скорость ремонта зависит от того, насколько форма детали подходит к пробоине. |
| **Активаторный захват** | Коротким импульсом повышает восприимчивость цели к тяговому полю и затем подтягивает её основным лучом. | **Тросовый захват**. Трос с захватной головкой передаёт тягу непосредственно грузу. В качестве модового допущения головка сама долетает до контейнера, разматывая трос. Если контейнер кувыркается, подтягивание начинается после закрепления головки. |
| **Экранирующий генератор (КР1) / коротковолновый генератор (КР2)** | Первый ослабляет удар несколькими слоями поля. Второй формирует один тонкий слой у обшивки и рассчитан на штатное питание серийных кораблей. | **Панельный генератор защиты**. Излучатели формируют отдельные защитные панели возле обшивки. Панели защищают отдельные участки корпуса. На стыках поля слабее, поэтому попадание под косым углом даёт больше нагрузки на обшивку. |

## ГТУ 8. Управление внутренней структурой

Переход КР1 → КР2

| Оборудование КР1 / КР2 | Принцип работы | «Дети Эльтан» |
|---|---|---|
| **Мезоструктурный корпус** | Внутренняя сеть перемычек в бронеплите последовательно деформируется под ударом. Более дешёвые варианты конструкции пошли в массовые серии КР2. | **Индукционный корпус**. Индукционные контуры в обшивке перераспределяют часть нагрузки на соседние панели. При деформации меняется отклик контура, и ближайшие панели принимают часть удара. Рамному предшественнику для этого служили только механические связи. |
| **Сингулярный двигатель** | Формирует гиперпереход вокруг компактного фокуса искривления. Послевоенное исполнение ограничивает искривление вследствие запрета режимов с риском коллапса в чёрную дыру. | **Электротяговый двигатель**. Электрическое поле ускоряет заряженное рабочее тело. Поле регулирует разгон рабочего тела быстрее роторного дозатора. В прыжковом режиме стабильная подача уменьшает просадки мощности. |
| **Гипержидкостный бак (КР1) / конденсатный бак (КР2)** | Первый хранит запас в плотной текучей фазе. Во второй на заправке осаждают плотный твёрдый конденсат. В полёте бак разжижает тонкий поверхностный слой и подаёт топливо в расходную камеру. | **Магнитозапорный топливный бак**. Магнитное поле удерживает топливо у горловины и управляет подачей. Запор действует на чувствительную к полю фазу у выходного канала. Подачу можно перекрыть без перемещения тяжёлого клапана. |
| **Субтрансферный радар** | Часть сигнала проходит через приграничный слой гиперпространства. Прибор сверяет отклик с обычным эхо. У серийного исполнения КР2 меньшая мощность и дальность. | **Контурный радар**. Замкнутый контур разнесённых антенн объединяет измерения по периметру корпуса. Пока часть антенн ведёт обзор, остальные подтверждают слабые отметки. Общий контур позволяет сравнивать сигнал с разных бортов. |
| **Вортексный сканер** | Вращающееся поле зондирования собирает отклики под разными углами и выделяет устойчивые признаки содержимого. | **Электрозондовый сканер**. Электрический зонд измеряет отклик материалов за защитой. Зонд различает материалы по тому, как они меняют электрический отклик. Это даёт дополнительный признак, когда спектр под защитой читать трудно. |
| **Суспензорный дроид** | Удерживает ремонтную взвесь полем, распределяет её по форме пробоины и закрепляет на обшивке. | **Электросварочный дроид**. Электросварка восстанавливает непрерывность металлической обшивки. Сварной шов возвращает плите часть несущей способности. Сборочный дроид удерживал вставку крепежом, а электрический шов связывает с ней края обшивки. |
| **Телекинетический захват** | Воздействует на объём груза, подтягивая его и гася вращение. Серийная модель КР2 рассчитана на питание малого корабля. | **Магнитополевой захват**. Магнитное поле наводит в материале цели отклик, через который передаётся тяга. Поле дотягивается до груза без выпуска головки. | **Деатомарный сканер** | Различает отклики отдельных элементов в составе предметов. По их сочетаниям восстанавливает состав груза даже при сильном ослаблении сигнала защитой. | **Фазопроникающий сканер**. Подбирает фазу импульса по отклику защиты и извлекает признаки содержимого. Сканер уточняет фазу по каждому отражению. Следующий импульс проходит через защиту с меньшим искажением. |
| **Штифтовый дроид** | Сшивает уцелевшие края повреждённой плиты короткими штифтами, ориентируя их по данным о нагрузке. Такая фиксация позволяет быстрее вернуть прочность до завершения наружной заплаты. | **Фазосинхронный дроид**. Согласует фазы полей и движения инструментов, чтобы несколько головок работали на одном повреждении. Несколько головок могут готовить и закреплять один шов одновременно. Согласование позволяет избежать взаимных помех и повторной подгонки. |
| **Оптоволновой захват** | Волоконная сеть распределяет импульсы от общего источника по разнесённым излучателям и согласует их работу. Поле меньше теряет форму на дистанции, поэтому захват удерживает более тяжёлый груз. | **Фазосцепный захват**. Согласует поле с откликом материала и распределяет тягу по разным частям груза. Поле выравнивает сцепление с частями объекта разной формы и плотности. Это помогает удерживать крупный вращающийся обломок. |
| **Микроуровневый генератор защиты** | Делит защитную оболочку на множество малых областей. При попадании включает нужные области и ближайшее окружение, концентрируя мощность в месте удара. | **Фазоотражательный генератор защиты**. Подстраивает фазу защитного поля так, чтобы часть энергии воздействия рассеивалась от корпуса. Настройку меняют по характеру воздействия. Часть энергии рассеивается в наружном слое поля, снижая нагрузку на обшивку. |

## ГТУ 14. Точная настройка материалов, полей и сигналов

КР2 · рабочий вариант для мода. Трактовки принципов работы предложены для обсуждения.

| Оборудование КР1 / КР2 | Принцип работы | «Дети Эльтан» |
|---|---|---|
| **Биослотовый корпус** | В силовом наборе предусмотрены посадочные гнёзда с биокомпозитными стенками. Они обрастают установленную деталь и передают нагрузку в обшивку без ослабления вокруг крепления. Название отсылает к клисанским биослотам в мегапанцире, которые клисаны могли заращивать оружием. | **Метрикоустойчивый корпус**. Силовой набор распределяет нагрузки, возникающие при локальном искривлении пространства у корабля. Сочленения направляют неравномерную нагрузку на несколько секций сразу. Обшивка лучше переносит как удар, так и деформации при работе корабельных полей. |
| **Темпоральный двигатель** | Синхронизирует излучатели по локальному времени в разных частях гиперперехода. При искажении хода времени автоматика корректирует момент подачи каждого импульса. Переход остаётся устойчивым дольше, поэтому растёт дальность прыжка в пределах допустимого искривления. | **Метрикосдвиговый двигатель**. Изменяет геометрию пространства вокруг корабля и вдоль гиперперехода в допустимых рабочих пределах. Распределение искривления вдоль перехода даёт более дальний прыжок в рамках разрешённых режимов. При манёвре поле помогает направить рабочее тело. |
| **Текриновый топливный бак** | В рабочей трактовке текрин — материал тонких внутренних перегородок, удерживающих топливо в плотном состоянии. При подаче освобождается только ближайшая к выходу порция. Неподвижное хранилище обходится без вращающегося барабана и оставляет больше места под запас. | **Складчатый топливный бак**. Хранит топливо в ограниченной складке пространства, увеличивая полезный внутренний объём. Складка поддерживается внутри камеры. Заборник переводит порцию в обычный объём перед подачей в магистраль. |
| **Нуль-контактный радар** | Измеряет, как масса объекта меняет фазу контрольного сигнала на проходящей рядом трассе. Для обнаружения достаточно уловить это возмущение. Название относится к режиму, в котором зондирующий сигнал проходит мимо цели, а дальность выигрывает за счёт чувствительности к слабым изменениям фазы. | **Геодезический радар**. Определяет положение объектов по отклонению контрольных трасс от расчётной геометрии. Приёмники сверяют несколько контрольных трасс. Совпадение отклонений позволяет выделить положение цели по слабому сигналу. |
| **Кванторный сканер** | Измеряет отдельные порции энергии в отклике и по их сочетаниям восстанавливает сигнатуры вещества. Деатомарный определял, какие элементы есть в грузе. Кванторный различает ещё и состояния, в которых они находятся, поэтому может распознать характерные материалы даже по неполному сигналу из-под защиты. | **Метрический сканер**. Восстанавливает внутреннее строение цели по тому, как её содержимое изменяет контрольное поле. Возмущения поля с разных направлений дают карту внутренних неоднородностей. По ней прибор выделяет груз и оборудование даже через сильную защиту. |
| **Дуплексный дроид** | Две рабочие головки действуют с разных сторон повреждения. Пока одна фиксирует края и ставит штифты, вторая закрывает пробоину и проверяет, как шов держит нагрузку. Параллельная работа ускоряет восстановление обшивки. | **Дистанционный дроид**. Дистанционно направляет ремонтные частицы и инструменты, восстанавливая несколько участков обшивки за цикл. Ремонтный блок удерживает инструменты и состав полем на удалении от корпуса. Несколько операций можно провести без перелёта основного модуля. |
| **Микротональный захват** | Меняет частоту тягового поля малыми шагами и по отклику подбирает режим для разных частей груза. Это позволяет распределить тягу по объекту и удержать его при вращении. По сравнению с оптоволновым захватом точнее настраивается само воздействие на груз. | **Складчатый захват**. Локально изгибает путь, по которому поле перемещает груз к приёмному отсеку. Складка формирует путь для транспортировки. Захват удерживает груз на этой траектории и выравнивает его перед приёмом. |
| **Ультраплазменный генератор защиты** | Удерживает в поле многослойный веер сильно ионизированной плазмы. Наружные слои поглощают часть энергии удара и отводят её вдоль оболочки, внутренние поддерживают защиту, пока внешний слой восстанавливается. Для мода это позднее развитие клисанского плазмощита, у которого плазма уже поглощала энергию. | **Кривизный генератор защиты**. Искривляет траектории входящего воздействия и отводит часть энергии в сторону от обшивки. Генератор усиливает искривление возле ожидаемой точки попадания. Часть воздействия проходит вдоль оболочки и рассеивается вдали от места удара. |
