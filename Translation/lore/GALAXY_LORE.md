# Лор вселенной Space Rangers по лангам игры (КР1, КР2, КР2 HD)

Источник истины — ланги игры в `Translation/lore/source/` (cp1251, не менять):
`SR1_rus.txt` — КР1 (~3000 г.), `SR2_rus.txt` — КР2 (~3300 г.), `SRHD_rus.txt` — КР2 HD.
Каноничность: **КР1 и КР2 главнее HD**. HD — расширение КР2: квесты/записи КР2 есть и в HD
(иногда переписаны), новое в HD идёт сверх КР2. Расхождение HD с КР2 — метка `[противоречие]`.

Инструмент: `python3 qlore.py ... < /dev/null` (dump / find / get / check — см. шапку скрипта).

## Правила записи
- **Каждый факт — со ссылкой** на ланг и ключ: `[SR2:Quest.DefShip.17.Start]`; `#N` — N-я строка
  повторяющегося ключа. Есть одинаково в КР2 и HD — `[SR2, SRHD:ключ]`; ключи разные — обе ссылки.
- **Эпоха** у каждого факта: `КР1` (~3000 г.) или `КР2` (~3300 г.; КР2 и HD — одна эпоха).
- **Метки достоверности:** `[факт]` прямо сказано · `[мнение]` говорит персонаж/раса, пристрастно ·
  `[развенчано]` опровергнуто в развязке квеста · `[вывод]` наш · `[противоречие]` источники расходятся ·
  `[под вопросом]` существование/правдивость сомнительны внутри мира.
- **Мнение одной расы о другой** — в обе расы (в «Отношение к …» каждой).
- **Пародии, шутки, отсылки** — в `GALAXY_LORE_PARODY.md`; **спорное «лор ли это»** — в `GALAXY_LORE_DOUBTS.md`.
- **Персонажи-цели** (защита — DefShip, устранение — KillShip): факты до развязки — фактами;
  «раскрыто в финале» (правда о мире, не зависящая от выбора игрока) — фактом с пометкой;
  **судьба — только вариантами** (защищён / убит после контракта / охрана провалена;
  убит рейнджером / жив), канон не выбираем.
- Ветки квеста: `Start` — завязка; `End` — успех; `Special` — у DefShip «погиб после окончания
  контракта», у прочих — альтернативная развязка.

## Прогресс (блоки; [x] — пройдено полностью)
1. [ ] Квесты DefShip / KillShip / DefSystem / SendLetter: КР2 (SR2 0..N, + изменения HD) → HD сверх КР2 → КР1
2. [ ] Race, Planet, Star, GalaxyNews, Help, Tips, FormIntroduction
3. [ ] GovGreetings, ShipGreetings
4. [ ] Artefacts, Items, MicroModuls, Illness, Reward
5. [ ] Script (MS_*, PC_*), FormRuins, Talk
6. [ ] RobotsMap, ABMap, PlanetQuest
7. [ ] Остальное

Формат факта: `- [метка] КР2. Текст факта. [SR2:ключ; SRHD:ключ]`
Формат персонажа:
```
#### Имя — раса, роль (цель защиты / цель устранения / заказчик / упоминается), эпоха
- [факт] … [ссылка]
- Раскрыто в финале: … [ссылка]
- Варианты судьбы: … [ссылки]
```
