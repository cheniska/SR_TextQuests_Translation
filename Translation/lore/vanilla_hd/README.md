# Ванильный русский ланг КР2 HD

[Оригинал](../source/SR_2_HD_Lang_vanilla.txt), UTF-16 LE, Git-объект `08918ae0262f64a993f7c943927834a3b7fa220f`. [Построчный указатель блоков](BLOCKS.md) охватывает все 16295 присваиваний с русским текстом. Блоки без русских значений опущены. Номер строки относится к оригиналу, а `#N` в ключе обозначает повтор значения с тем же именем поля. Если GitHub предложит скачать UTF-16, откройте скачанный оригинал и перейдите к указанной строке. Ключи `Script.PC_*` используют принятую в своде группировку сценариев.

## Статус разбора

- «Разобрано по оригиналу» — ручной вывод по конкретной реплике. Слухи, слова заказчиков и условные исходы отмечены в формулировке.
- «Разобрано в своде» — найдено совпадение текста с записью, уже имеющей ссылку в своде, отсылках или спорных материалах. Ссылка на свод может вести к составному выводу из нескольких строк.
- «Кандидат» — есть тематический сигнал. «Требует контекста» — строка включена в построчный указатель, самостоятельный факт пока не выделен. Фрагменты этих строк служат ориентирами для дальнейшей сверки.
- «Каталог» — имя или топоним из набора названий. Имя из генератора само по себе не подтверждает существование конкретного персонажа.
- «Интерфейс» / «Реплика» — подпись, техническое сообщение или короткая реакция без выделенного лорного факта.
