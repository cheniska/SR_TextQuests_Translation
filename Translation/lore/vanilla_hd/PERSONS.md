# Персонажи

## Факты из ванильного ланга

- Селланори и Мутник программировали базы доминаторов для турнира «Перекрестный огонь». [Ванильный ланг, строка 19602 · `RobotsMap.53.RobotsWin#1`](../source/SR_2_HD_Lang_vanilla.txt#L19602).
- В ветке поражения Селланори и Мутник остаются претендентами на основную часть призового фонда. Реплика называет двух программистов человеком и фэянином, без привязки рас к именам. [Ванильный ланг, строка 19595 · `RobotsMap.53.RobotsLoss`](../source/SR_2_HD_Lang_vanilla.txt#L19595).
- Олмиан Селланори — разыскиваемый в десяти системах программист, изобретатель и хакер. Дазыкагз Сиша возглавляет пеленгский наркосиндикат «Скользкие руки». Оба связаны с плантацией из задания «План». [Ванильный ланг, строка 19822 · `RobotsMap.63.GovTextStart`](../source/SR_2_HD_Lang_vanilla.txt#L19822).
- В ветке победы С.В.А.Х.А. задерживает Сишу, а Селланори уходит от ареста. [Ванильный ланг, строка 19823 · `RobotsMap.63.GovTextWin`](../source/SR_2_HD_Lang_vanilla.txt#L19823).
- Генерал Грубахар, по рассказу малокского заказчика, разбил лагерь рядом с карапской пирамидой и уничтожил её захваченными орудиями карапов. [Ванильный ланг, строка 19657 · `RobotsMap.56.GovTextStart#1`](../source/SR_2_HD_Lang_vanilla.txt#L19657).
- Малокский собеседник называет Грубахара основателем своей страны. По прибытии к лагерю ему по традиции отдают честь; слова о духе генерала передают представление собеседника. [Ванильный ланг, строка 19671 · `RobotsMap.56.RobotsStart`](../source/SR_2_HD_Lang_vanilla.txt#L19671).
- Доктор Индий Джокс — известный археолог, чья экспедиция открыла действующую карапскую пирамиду с сохранившимися архивами. [Ванильный ланг, строка 19800 · `RobotsMap.62.GovTextStart`](../source/SR_2_HD_Lang_vanilla.txt#L19800).
- Рачехан связан с гиперпузырём «Рачехания» по местным слухам. Описание называет нынешних посетителей пузыря пиратами клана «Дети Рачехана». [Ванильный ланг, строка 116 · `ABMap.15.Desc`](../source/SR_2_HD_Lang_vanilla.txt#L116).
- Кроолдин — известный гаальский учёный-мыслитель, создатель искусственного пузыря «Артификал». [Ванильный ланг, строка 68 · `ABMap.09.Desc`](../source/SR_2_HD_Lang_vanilla.txt#L68).
- Первооткрыватель «Арены Реегбара» погиб внутри пузыря. Повреждение двигателя при столкновении с шипами приведено как официальная версия. [Ванильный ланг, строка 100 · `ABMap.13.Desc`](../source/SR_2_HD_Lang_vanilla.txt#L100).
