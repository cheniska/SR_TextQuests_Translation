# Флора

## Факты из ванильного ланга

- Опиумные саговники служат сырьём для элитных натуральных наркотиков. В задании «План» их выращивают на островной плантации. [Ванильный ланг, строка 19822 · `RobotsMap.63.GovTextStart`](../source/SR_2_HD_Lang_vanilla.txt#L19822).
- На вулканическом острове «Аленький», по данным местных исследователей, растёт почти сто видов растений. Там сохранился последний экземпляр красного цветка, название которого утрачено. [Ванильный ланг, строка 18195 · `RobotsMap.03.GovTextStart#3`](../source/SR_2_HD_Lang_vanilla.txt#L18195).
