# Перевод текстовых квестов RU → EN: инструкция (один квест за сессию)

Читать целиком в начале каждой сессии перевода. Лор — отдельная инструкция: `LORE_GUIDE.md`.

## Правила
- Работаем **только с txt**. qmm не трогаем (решение пользователя).
- Исходник (RU) **никогда не правим**. Результат — новый файл.
- Один квест за сессию: перевод → проверка `qtr.py` → лор → обновить `STATUS.md`.
- Язык общения — русский; текст квеста — английский.
- Python только так: `py -3.14 файл.py < /dev/null`. Никогда `py -3.14 -`.
  В Bash перед запуском: `export PYTHONUTF8=1` (иначе кириллица бьётся).

- **Русские txt не изменяются никогда** (ни исправления опечаток, ни форматирования). Все правки — только в
  рабочей копии и в новом английском файле.
- **Термины и имена.** Встретился игровой термин, имя, название (планета, раса, организация, предмет,
  должность, жаргон) — **сообщить пользователю** в ответе сессии (строка «Новые термины: RU → EN, где
  встретился») и **сразу занести в `GLOSSARY.md`** (RU, EN, категория, квест, тип записи, комментарий).
  Если термин уже есть — использовать как в глоссарии; если вариант перевода спорный — указать
  альтернативы и выбранный вариант, и сообщить об этом.

- **Повторяющиеся фразы переводятся одинаково.** Из-за структуры квестов (повторы локаций, параметров,
  вариантов с разными условиями) многие записи совпадают на 90–100%. Правила:
  - Точные повторы (одинаковый русский текст) → **строго одинаковый английский**, посимвольно.
  - Почти повторы (≥90%) → перевод **тоже почти одинаковый**: отличаются ровно в тех местах, где
    различается оригинал, формулировка остальной части та же. Не перефразировать «для разнообразия».
  - Сначала `py -3.14 qtr.py dups "<RU txt>" < /dev/null` (после unpack) — список групп точных и
    почти повторов; переводить первую запись группы, остальные строить копированием и правкой различий.
  - `check`/`pack` проверяют это: одинаковый RU с разным EN = **ошибка**, почти одинаковый RU с
    непохожим EN = предупреждение (разобрать каждое).
  - То же между квестами: типовые фразы (меню, «Вы мертвы», статусы) брать из глоссария/уже
    переведённых квестов и не переформулировать.

## Пути
| Что | Где |
|---|---|
| Исходник RU | `QUESTS\TextQuests\<Мод>\Rus\<Name>.txt` (для SR2HD: `SR2HD\questsRus\<Name>.txt`) |
| Результат EN | `QUESTS\TextQuests\<Мод>\Eng\<Name>.txt` (SR2HD: `questsEng\<Name>_eng.txt`) |
| Рабочая копия | `QUESTS\Translation\work\<Name>.work.txt` (UTF-8, создаёт `qtr.py unpack`) |
| Инструмент | `QUESTS\qtr.py` |
| Лор | `QUESTS\Translation\lore\` (см. `LORE_GUIDE.md`) |
| Глоссарий | `QUESTS\Translation\GLOSSARY.md` |
| Очередь и статус | `QUESTS\Translation\STATUS.md` |

В `SR2HD\questsEng\*_eng.txt` сейчас лежит **русский** текст для 32 квестов и частично английский для 6
(см. `STATUS.md`) — перезаписываем их переводом только после проверки `qtr.py pack`.

## Формат txt (TGE)
- Кодировка UTF-16LE + BOM, CRLF. Строка: `<Тип>\t<текст>`. Продолжение текста — строки `*\t...`
  (пустая строка внутри текста = `*\t`). Переносы строк внутри текста — через эти `*`-строки.
- Типы: `QuestDescription`, `QuestSuccessGovMessage`, `Par<N>-<k>`, `Par<N>-crit`, `Loc<N>-<k>`,
  `Loc<N>-par<P>-crit`, `Path<N>`, `Path<N>b`, `Path<N>-par<P>-crit`.
- **Тип (до TAB) не менять, записи не удалять/не переставлять/не добавлять.**
- Работаем в UTF-8 рабочей копии; `pack` сам вернёт UTF-16LE+BOM.

## Разметка внутри текста — сохранять дословно (не переводить)
`<clr>…<clrEnd>` (цвет; переводить только текст между ними), `<Ranger>`, `<ToPlanet>`, `<FromPlanet>`,
`<Money>`, `<br>`, `<fix>…</fix>`, `<format=left,3>…</format>`, `<format=center,33>`, параметры `[p12]`,
формулы `{[p7]-[p25]}`, `{[p11] mod 10}`, а также любые другие `<…>` / `{…}` / `[pN]`.
Пустые `<>` (например «В магазине винтовки <> патрон») — это подстановка числа: оставить как есть,
**перестроить фразу под английскую грамматику** (мн. число: `<> rounds`). Склонения русских
числительных (патрон/патрона/патронов, записи Par9-2..7) — в английском дают только «1 / не 1»;
лишние варианты записей оставляем, но дублируем нужную форму, типы не удаляем.
`pack` сверяет мультимножество токенов разметки записи с исходником — расхождение = ошибка.

## Шаги
1. **Подготовка.** Взять следующий квест из `STATUS.md` (статус `todo`). Проверить, не лежит ли уже
   английский черновик: `0_квесты кр 2 тхт\qmm_to_translate\_преев\Новая папка\<name>*.txt` и
   `0_квесты кр 1 в тхт англ\…`. Черновик — только подсказка: читать критически, перепроверять по RU.
2. `py -3.14 qtr.py unpack "<путь к RU txt>" < /dev/null` → создаётся `work\<Name>.work.txt`.
   Затем `py -3.14 qtr.py dups "<путь к RU txt>" < /dev/null` — карта повторов (см. правило выше).
3. **Прочитать квест целиком** (по кускам, `Read` с offset/limit), понять сюжет, персонажей, параметры
   (`Par*`), развилки. Составить список имён/терминов квеста; свериться с `GLOSSARY.md` и с уже
   переведёнными квестами (`Grep` по `SR2HD\questsEng`, `0_квесты кр 1 в тхт англ\qmm`) — термины единые.
4. **Переводить — рекомендуемый метод для больших квестов (проверен на Moi, 1227 записей):**
   а) `py -3.14 qtr.py todo "<RU txt>" work\<Name>.todo.txt < /dev/null` — файл только с первыми вхождениями
      уникальных RU-текстов (точные повторы отсеяны; Moi: 1063 из 1227);
   б) читать todo кусками ~250 строк (`Read` с offset/limit), переводить каждый кусок в новый файл
      `work\<Name>.p01.txt`, `.p02.txt`… (типы и `*`-строки как в todo, кусок обязательно заканчивать на границе
      записи — следующий кусок начинается со строки с типом, а не с `*`);
   в) после каждого куска: `py -3.14 qtr_partcheck.py <Name> < /dev/null` (типы, токены, число строк, кириллица);
   г) когда все куски готовы: `cat work\<Name>.p??.txt > work\<Name>.todo_en.txt`, затем
      `py -3.14 qtr.py fill "<RU txt>" work\<Name>.todo_en.txt work\<Name>.work.txt < /dev/null` —
      раскладывает перевод на точные повторы (одинаковый RU → одинаковый EN автоматически).
   Для маленьких квестов можно править `.work.txt` напрямую (Edit по блоку записей).
   Near-дубли (≥90%) переводить по карте `dups`: копировать перевод соседней записи и править различия.
   Пустая строка продолжения (`*` без TAB) в кусках допустима — `qtr.py` сам восстановит `*<TAB>`.
5. **Проверка:** `py -3.14 qtr.py check work\<Name>.work.txt "<RU txt>" < /dev/null`.
   Ошибки = 0 обязательно (типы, токены, пустые переводы). Предупреждения «осталась кириллица»
   должны быть пусты, кроме осознанных (имя на кириллице в оригинале и т.п. — записать в `STATUS.md`).
6. **Запись:** `py -3.14 qtr.py pack work\<Name>.work.txt "<RU txt>" "<Eng txt>" < /dev/null`.
7. **Лор:** по `LORE_GUIDE.md` — добавить факты в `lore\LORE_FACTS.md`.
8. **Заметки к переводу:** файл `questsEng\notes\<Name>_notes.txt` рядом с результатом (для модов - `Eng\notes\`):
   все АДАПТАЦИИ, ПОТЕРИ, СОМНЕНИЯ, ПАРОДИИ и новые слова по записям (образец - `SR2HD\questsEng\notes\Moi_notes.txt`).
   Вести по ходу перевода, не по памяти.
9. **Учёт:** в `STATUS.md` поставить `done`, дату, число записей, заметки; новые термины — в
   `GLOSSARY.md` (и список новых терминов в итоговом сообщении пользователю). Удалить рабочую копию.

## Стиль перевода
- Это игровой юмор Space Rangers: сохранять шутки, каламбуры, пародии. Если каламбур не переносится —
  заменить по смыслу и отметить в `STATUS.md` («адаптация»).
- Тон оригинала (пафос, канцелярит, жаргон пеленгов/малоков) сохранять. Обращение к игроку — `you`,
  наклонение/время как в оригинале (обычно прошедшее, 2-е лицо: «Вы подошли…» → «You approached…»).
- Единая терминология с официальным английским SR2 (Peleng, Gaal, Maloq, Faeyan, Klissan, Dominators,
  Rangers, credits/cr и т.д. — см. `GLOSSARY.md`). Имена собственные — как в глоссарии или
  транслитерация; новое имя — добавить в глоссарий сразу.
- Цифры, единицы, проценты, `cr` — не менять. Проверять, что текст влезает по смыслу в вариант
  ответа (короткие пункты выбора).
- Кавычки/тире: прямые `"`, дефис-тире ` - ` в репликах как в оригинале.
- Числа-пароли, ответы на загадки, коды в текстах — **не менять без проверки логики**: если загадка
  построена на русских словах/буквах (акростих, анаграмма, рифма) — перерабатывать и
  сверять с логикой квеста (условия переходов в qmm **нельзя** править, поэтому ответ-число/код
  оставляем, меняем только текст подсказки). Отмечать в `STATUS.md`.
- Не оставлять русских букв, в т.ч. «похожих» кириллических (С, о, а, е, р, х) внутри латиницы
  (такое уже ловили: `Case` в Mafia `Par30-2`). `check` это ловит.

## Корпус КР1
Для квестов КР1, у которых английский уже есть, — вычитка вместо перевода: см. `KR1_REVIEW_GUIDE.md`.

## Мелкие точки
- Пустые записи не экспортируются; пустой перевод непустого исходника — ошибка.
- Если формат RU txt нарушен (`qmm_txt.py` не парсит) — сначала починить копию, см. историю «почини форматы».
- Параллельный английский txt для мод-квестов кладём в соответствующую `Eng\`.

## Имена собственные (решение пользователя 2026-10-01)
Имена людей/персонажей **транслитерируем, не адаптируем** (Дуб О'Лом → Dub O'Lom, В. Долбановский → V. Dolbanovsky), даже если в оригинале каламбур; пояснение — в notes/лоре. Орфография английского текста — американская (defense, color).

## Время глаголов (решение пользователя 2026-10-01)
Не переводить всё в прошедшее. Время — по контексту русской записи: записи, где русский преимущественно в настоящем (состояния «вы видите», «лежит», концовки «Остаётся только…»), остаются в настоящем; повествование в прошедшем — в Past Simple. Внутри одной записи время единое (дрейф в оригинале выравниваем по доминирующему). Эвристика: `Translation\work\tense.py <Rus.txt> <мин.глаголов>` (сохранить в QUESTS при необходимости).
