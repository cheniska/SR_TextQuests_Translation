# ShuMercsHQ RU→EN: рабочие заметки (обновлять по ходу)

Пайплайн: `mercs.txt` (UTF-8 копия Rus/Lang.txt) → `items.tsv` (строка, путь, RU) → `todo.txt` (2196 уникальных RU, `N<TAB>текст`) → переводы `pNN.txt` (`N<TAB>EN`) → `tools/pc.py` (проверка токенов/кириллицы) → `tools/ap.py` собирает `CFG/Eng/Lang.txt` (UTF-16LE+BOM, CRLF).
Скрипты принимают путь к рабочему каталогу S (внутри — `mercs.txt`, `items.tsv`, `w/todo.txt`, `w/pNN.txt`).
