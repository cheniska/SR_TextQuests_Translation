1	The ShipTypes parameter determines which ship types will receive programs at all. The parameters named after ship types determine the list of programs received by that ship type. The first number in a parameter is the overall chance for that ship to receive an info item for using programs, as well as the chance of replenishing that particular ship's stock of programs if its number of programs is not yet at maximum. The number after the colon following the first one is the maximum number of programs that can be in stock on a ship of that type at one time (plus the same number of "Intercoms"). A program name and the number after the colon is the chance of the ship receiving that particular program upon replenishment. The total sum of the chances of receiving the various programs must be 100%. Also remember to update the Version parameter when making any changes, otherwise the changes will not be applied to game saves.
2	Number of runs: <Data1> pcs.
3	This info item is used only as a marker. When any anti-dominator program is added to a bot, one "Intercom" is automatically added to it as well, for the nominal ability to activate it.
4	Used to automatically replenish the stock of programs for an NPC that has this info item
