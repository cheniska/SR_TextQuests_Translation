Параметр Size обязателен (если вы точно уверены, что в моде с данным артефактом в разделе арта Size прописан, то здесь его можно не писать), но работает только для кастомных артефактов, не являющихся юзлесными предметами. Параметр Cost напрямую влияет на расчёт конечной стоимости артефакта, при этом учтите, что дешёвым артефактом считается артефакт с Cost=1000, а дорогим с Cost=2500. Выставлять значение Cost сильно ниже или сильно выше указанных значений не рекомендуется. Всем прочим артефактам и предметам данные параметры указывать не нужно (кодом они учтены не будут).	The SpawnRateChance parameter is responsible for how often the artifact appears in the store. The NoneRaceChance parameter is responsible for the chance of the artifact receiving an unknown race. The Owner parameter (races may be listed separated by commas without spaces, where the value Coalition is interpreted as the 5 main game races) is optional and will be applied if the artifact does not receive an unknown race. By default the Owner parameter equals all Coalition races; in other respects it works the same as in the lists above. The Size parameter is mandatory (if you are absolutely sure that Size is specified in the artifact's art section in the mod, you may omit it here), but works only for custom artifacts that are not useless items. The weight of custom artifacts that are not useless items will be determined by an internal formula based on the value of the Size parameter. The situation is similar with the Cost parameter for custom artifacts. If it is present in the artifact's main section, specifying it is not required. The Cost parameter directly affects the calculation of the artifact's final price; note that an artifact with Cost=1000 is considered cheap and one with Cost=2500 expensive. Setting Cost far below or far above these values is not recommended. All other artifacts and items need not have these parameters specified (the code will not take them into account).

The CustomFactionChance and CustomFaction parameters are optional and can be set for any artifacts as desired. The ArtAdditionalCostCoef parameter denotes a modifier by which the artifact's cost will be multiplied after it is created (can take fractional values, the fractional part separated by a dot). The optional SubRace parameter denotes a dominator series (applies only to dominator artifacts) and has 3 values: Blazer, Keller, Terron, or Any (values may be added without spaces, separated by commas).
