184	The Owner parameter (races may be listed separated by commas without spaces, where the value Coalition is interpreted as the 5 main game races) is advisable to fill in only for custom guns (by default, without it, all races except dominators and the unknown one will be chosen), and for original guns Owner will by default be taken from the main game (3 dominator-only, 3 pirate-only, the rest for everyone). The value Any in Owner is always interpreted as all races except the unknown one. The AverageSize parameter (meaning average weight, where N/2 is the minimum weight and N*2 is the maximum) is purely optional, and if absent the weight will be taken from the gun's main parameters. The Owner parameter for modifications is optional; by default it will be taken from the acryn section of that modification, and if it is absent there, inherited from the Owner of the main gun. If a custom weapon is added to the list, the Origin parameter must specify the exact name of the script of the mod in which that weapon is declared. The CustomFactionChance and CustomFaction parameters (different factions may be listed separated by commas without gaps) are optional and need not be added. All other parameters (including the Count counters) are strictly mandatory for any gun.
185	An unknown race for any weapon can be obtained only through the chance specified in the NoneRaceChance parameter, and the minimum weight can be obtained both through a random roll and through the chance specified in the MinSizeChance parameter. The DomRaceCostCoef and NoneRaceCostCoef modifiers (which can take fractional values) are used to increase the cost of items (right before they are added to the store) that have a dominator race and an unknown race, respectively. The optional SubRace parameter denotes a dominator series (applies only to dominator weapons/modifications) and has 3 values: Blazer, Keller, Terron, or Any (values may be added without spaces, separated by commas).
186	Separate optional parameters Owner, CustomFactionChance, and CustomFaction can be set for weapon modifications. When a weapon is created in the script, the race values will be taken from the modification if a weapon with a modification is being created, and from the weapon's main section if an unmodified gun is being created. In this way you can create, for example, weapon modifications belonging to some specific race or races, whether original or custom, even though the main unmodified weapon will be available for production to everyone else.
