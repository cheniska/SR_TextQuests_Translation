14	The SpawnRateChance parameter is responsible for how often the artifact appears in the store. The NoneRaceChance parameter is responsible for the chance of the artifact receiving an unknown race. The Owner parameter (races may be listed separated by commas without spaces, where the value Coalition is interpreted as the 5 main game races) is optional and will be applied if the artifact does not receive an unknown race. By default the Owner parameter equals all Coalition races; in other respects it works the same as in the lists above. The Size parameter is mandatory (if you are absolutely sure that Size is specified in the artifact's art section in the mod, you may omit it here), but works only for custom artifacts that are not useless items. The weight of custom artifacts that are not useless items will be determined by an internal formula based on the value of the Size parameter. The situation is similar with the Cost parameter for custom artifacts. If it is present in the artifact's main section, specifying it is not required. The Cost parameter directly affects the calculation of the artifact's final price; note that an artifact with Cost=1000 is considered cheap and one with Cost=2500 expensive. Setting Cost far below or far above these values is not recommended. All other artifacts and items need not have these parameters specified (the code will not take them into account).
15	The CustomFactionChance and CustomFaction parameters are optional and can be set for any artifacts as desired. The ArtAdditionalCostCoef parameter denotes a modifier by which the artifact's cost will be multiplied after it is created (can take fractional values, the fractional part separated by a dot). The optional SubRace parameter denotes a dominator series (applies only to dominator artifacts) and has 3 values: Blazer, Keller, Terron, or Any (values may be added without spaces, separated by commas).

112	The ItemType parameter is strictly mandatory and must contain one equipment type, with no lists. The possible type names for the ItemType parameter can be found in the SellingWithoutAcrynChance section. The Owner parameter (races may be listed separated by commas without spaces, where the value Coalition is interpreted as the 5 main game races) is optional and will replace the same parameter from the acryn's main section (races may be listed separated by commas without spaces); if it is absent there, the default is taken (all races except dominators and the unknown one). The value Any in Owner is always interpreted as all races except the unknown one. The AverageSize parameter (meaning average weight, where N/2 is the minimum weight and N*2 is the maximum) is optional, and if absent the weight will be calculated inside the script on general grounds. The CustomFactionChance and CustomFaction parameters (different factions may be listed separated by commas without spaces) are optional and need not be added. All other parameters (including the Count counters) are strictly mandatory for any acryn.
113	An unknown race for any item can be obtained only through the chance specified in the NoneRaceChance parameter, and the minimum weight can be obtained both through a random roll and through the chance specified in the MinSizeChance parameter. The DomRaceCostCoef and NoneRaceCostCoef modifiers (which can take fractional values) are used to increase the cost of items (right before they are added to the store) that have a dominator race and an unknown race, respectively. The optional SubRace parameter denotes a dominator series (applies only to dominator equipment) and has 3 values: Blazer, Keller, Terron, or Any (values may be added without spaces, separated by commas). If BonusNum is set to None, this equipment will always appear in the store without acryn.
114	The parameters inside the SellingWithoutAcrynChance section determine the chance that the corresponding equipment type appears in the store without acryn at all.

122	The Race parameter is read by the game almost like Owner, except that for a hull the unknown race None can be specified in Race. The HullType parameter allows the following possible values (only one value may be set, with no lists): Ranger, Warrior, Pirate, Transport, Liner, Diplomat, WarriorBig. The HullSerieChance parameter determines the chance with which one of the series listed in the HullSerie parameter will be applied to the hull (if HullSerieChance is not specified, the chance of a series being applied is set to 100%). The HullSerie parameter takes the names of sections with hull series (several series may be listed separated by commas without spaces). If the OwnerPirateClan value (the parameter is optional) is greater than zero, the hull will receive a pirate emblem even with a Coalition race (the emblem will have the color of the corresponding race). The CustomFactionChance and CustomFaction parameters (several factions may be listed separated by commas without spaces) are optional. The SellingChance parameter (a fractional number may be used) makes the hull's appearance on sale rarer - setting it to 0 or not setting it at all equates the chance to 100% (as does setting it to 100+).
123	The OneHullSellingChance, TwoHullsSellingChance, etc. parameters denote the chances with which 1, 2, 3, 4, or 5 hulls will appear for sale on the BM at the same time. The optional SubRace parameter denotes a dominator series (applies only to dominator hulls) and has 3 values: Blazer, Keller, Terron, or Any (values may be added without spaces, separated by commas).
124	Cost modifiers (CostCoef) can take fractional values (separate the fractional part with a dot). Before being added to the store, the cost of a micromodule will be multiplied by the given coefficients depending on the MM level.
