# OtherMods — заметки (38 модов с текстом собраны; GalKelicites — пустой Lang.txt, исходник без содержимого)

## Решения
- Моды SR1* (Epidemy, Equipment, GovernmentQuests, Gaals&Pirates, Malocs&Traders, PelengZond, RedSkull, TextQuests, ABMaps): английский ReduxOld использован только как подсказка, переведено заново (американская орфография).
- Звёзды RealStars — стандартные английские названия реальных звёзд (Betelgeuse, Fomalhaut, Alpheratz, Dschubba, Tyl…); суффикс `,Star.Normal/Small` сохранён.
- Названия микромодулей-выдумок: транслит (Regenat, Raketrim, Krinotan, Torpedant…); если RU — фонетика английского слова, то английское слово (Shield, Damage, Unlock, Buggy).
- WH40kGuns: канонические английские термины Warhammer 40,000 (Omnissiah, Adeptus Mechanicus, Skitarii, Tzeentch, Khorne, Nurgle, Carnifex, Ordo Hereticus, Golden Throne).
- Ранги пиратов (ProjectRogeria): Marauder → Raider → Ravager → Cutthroat; Верховные Лякуши = Supreme Lyakushas; шкала Рачехана = Rachekhan scale.
- Нисперовская серия доминаторов (ZelDomiks, DrKlesMod): Nisper, Keller, Blazer, Terron; Tranclucator, Smersh, bertor, vertix, IMHO-9000, shtip, equantor (по уже готовым модам).
- «ед.» в бонусах: units (как в тм-памяти); янвелб = ekup; Махпа/Махпелла = Makhpella.
- Gripper = захват; ГЗП = shield generator.
- «Шпик» (SR1PelengZond) = Sleuth (по старому Redux); «Красный Череп» = Red Skull, «Киттон» = Kitton.
- Геркулесовы имена SR1GovernmentQuests: Kalagon, Nikcher Dragit, Baduba-ren, Gotsok, Dread Axe (охранное агентство «Грозный топор»), Greenpeace Universal (GPU), Rahoncha, Gorpukh Mikhail, Khetriks, Gontsapok, Kangshis, Zhirik, Chubayken, Bushok, Bungar Mavrodi, Khakamaka.
